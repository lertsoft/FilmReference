# Film Color Reference 🎞️

An interactive web application for comparing the color science of various analog film stocks. This tool visualizes vectorscope analysis data using radar charts, allowing photographers to make informed decisions about which film stock involves the specific color comparisons they need for their projects.

## 🌟 Features

- **Interactive Radar Charts**: Visualize how different film stocks handle 6 primary color channels (Red, Yellow, Green, Cyan, Blue, Magenta).
- **Multi-Film Comparison**: Select and compare up to 3 different film stocks simultaneously against a neutral baseline.
- **Detailed Analysis**: View in-depth color science breakdowns, "Best For" use cases, and technical details for each film.
- **Internationalization**: Fully localized in English, Spanish, and French.
- **Responsive Design**: Seamless experience across desktop and mobile devices.
- **Dark/Light Mode**: Automatic theme detection with manual toggle.
- **Accessibility**: Built with a11y best practices, including screen reader support and keyboard navigation.

## 🚀 Tech Stack

- **Framework**: [SvelteKit](https://kit.svelte.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Runtime/Package Manager**: [Bun](https://bun.sh/)
- **Styling**: Native CSS with Custom Properties (Variables)
- **Icons**: Custom SVG icons & integration

## 🛠️ Getting Started

### Prerequisites

- [Bun](https://bun.sh/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/FilmReference.git
   cd FilmReference
   ```

2. Install dependencies:
   ```bash
   bun install
   ```

3. Start the development server:
   ```bash
   bun run dev
   ```

4. Open your browser and navigate to `http://localhost:5173`.
